How it runs

  1. Extract (Python, every morning in GitHub Actions): new rows from six counters on data.seattle.gov and hourly weather from Open-Meteo, stored as monthly Parquet files. Unchanged datasets are skipped; the last two months are re-fetched to pick up corrections.
  2. Transform and test (dbt on DuckDB): six differently shaped datasets become one hourly table, weather moves onto the counters' local clock (daylight saving included), and offline days are flagged. Data tests run on every build; if any fail, nothing is published.
  3. Publish: the marts are exported to JSON for this page.
